# Security policy

Resume Canvas holds people's personal details, so security reports are taken
seriously and handled before anything else.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub's
[security advisories](https://github.com/kstmostofa/resume-canvas/security/advisories/new)
for the repository, with:

- what an attacker could do, and to whom;
- steps to reproduce, using made-up resume content;
- the version or commit you tested.

You'll get an acknowledgement within a few days. Please give us a reasonable
time to fix the issue before disclosing it.

## Scope

Especially welcome: anything that lets resume content leave the browser
without the person asking, lets someone read a share link without its key,
injects script through resume content or an imported file, or abuses the AI
and share endpoints.
